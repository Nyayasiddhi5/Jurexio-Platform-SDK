# Nyayavigya Platform — Documentation Index (v3.1.2)

Single source of truth for every Nyayavigya markdown doc. Generated by `scripts/nv-doc-reorganize.ts` from inline classification + each doc's YAML header. Re-run the script to regenerate.

## Buckets

- **`completed_docs/`** — Describes shipped, merged behaviour. Treat as authoritative for current production.
- **`pending_implementation_docs/`** — Describes planned, partial, or deferred work. Subject to change as tasks land.
- **`superseded/`** — Older versions kept for historical reference. The `superseded_by:` header points to the current replacement.

## How to add a new doc

1. Pick the right bucket (`completed_docs/`, `pending_implementation_docs/`, or `superseded/`).
2. Add the doc with this 4-line YAML header at the top:

   ```
   ---
   status: completed | pending | superseded
   version: <e.g. 3.1.2 or v6.0.0>
   superseded_by: <docs/v3.1.2/.../NEWER.md or null>
   last_verified: <YYYY-MM-DD>
   ---
   ```

3. Add an entry for it in `scripts/nv-doc-reorganize.ts` (`CLASSIFICATION` array) and re-run the script. It will regenerate this index.
