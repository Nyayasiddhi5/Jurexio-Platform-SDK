# Workspace paths — uniform layout

| Environment | Path |
| --- | --- |
| **Mac (operator)** | `~/Desktop/cursor-workspace/Jurexio-Platform-sdk` (or `Jurexio-Platform` — same repo) |
| **Cursor Cloud Agent** | `/workspace` |
| **GitHub** | `https://github.com/Jurexio-Inc/Jurexio-SDK.git` |

Open **`Jurexio-Platform.code-workspace`** at repo root in VS Code / Cursor.

Legacy path `nyayavigya-platform-5.0.0-CURSOR-CLOUD/Jurexio-Platform-SDK` is **retired** — rename locally with:

```bash
mv ~/Desktop/cursor-workspace/nyayavigya-platform-5.0.0-CURSOR-CLOUD/Jurexio-Platform-SDK \
   ~/Desktop/cursor-workspace/Jurexio-Platform
```
